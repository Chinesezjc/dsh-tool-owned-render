渲染归工具所有 — ToolCard · Segment · 可选 Group

每个工具自己注册一个 React 组件，组合三个零件：ToolCard(卡片框，工具可自己画/替换) · Segment(核心单元，多数工具直接组合它) · 可选 Group(把多个 Segment 归到一个灯下，仅多执行工具用——多命令 bash / 交互回合)。 没有中央渲染分发，也没有 render-kind 联合。两条路：工具自写组件(主路) / generic 零代码兜底。 每个 Segment 内部是 [gutter][正文]，gutter 按 role 互斥：IN 段放灯；OUT 段放行号(仅 read/grep/diff，随正文滚)。 灯：绿成功 / 红失败 / 蓝运行 / 黄取消·超时 / 灰不可观察。滚动条用 ui-theme 主题化原生条(指针悬停 segment 才显)。
（灰「复制」为示意；⤢ 打开侧边预览面板的二级全屏示意）

蓝=运行 绿=成功 红=失败 黄=取消/超时 灰=不可观察
